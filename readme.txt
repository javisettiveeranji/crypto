🚀 CryptoPulse | Real-Time Crypto Tracker
CryptoPulse is a lightweight, mobile-responsive cryptocurrency dashboard that allows users to track the market's top assets, visualize price trends through interactive charts, and search for specific coins in real-time.

✨ Features
Real-Time Data: Fetches live market prices, price changes (24h), and market rankings via the CoinGecko API.

Interactive Charts: Dynamic price visualization using Chart.js with adjustable timeframes (24H, 7D, 30D).

Dynamic Search: Instant filtering of cryptocurrencies by name or symbol.

Dark & Light Mode: A sleek, system-aware theme toggle for comfortable viewing in any environment.

Mobile-First Design: Fully responsive CSS Grid and Flexbox layout optimized for both smartphones and desktops.

Smooth UX: Includes loading spinners, error handling for API rate limits, and smooth scroll-to-top functionality when switching coins.

🛠️ Built With
HTML5 & CSS3: Custom CSS variables for theming and sophisticated layout techniques.

JavaScript (ES6+): Fetch API for asynchronous data handling and DOM manipulation.

Chart.js: For rendering the high-performance price trend lines.

CoinGecko API: The world's most comprehensive independent cryptocurrency data source.
